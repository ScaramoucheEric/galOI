
# [P16789 [蓝桥杯 2026 国 A] 核心任务调度 反悔贪心](https://www.luogu.com.cn/problem/P16789)

### 题面简述：

给出 $N$ 个任务，每个任务有主要次要之分。给出每个任务的 deadline 和价值，要求最大化主要任务完成数量的同时，价值最高多少。

### 思路：

练习反悔贪心的好题。依旧从 DP 的思路（研究状态）看这道题。

现在需要维护的状态有：主要任务数量（最高优先级）、总价值、有哪些主 $/$ 次任务（用来反悔）。

然后就是反悔贪心的板子。

按照：

1. deadline 时间
2. 主 $/$ 次要任务
3. 价值

排序

然后开始贪心：

```cpp
priority_queue<...> p, q; // p、q 分别代表当前状态下，完成的主要任务有哪些，次要任务有哪些，方便反悔的喵。

for (Job i : arr) {
    if (i.main == true) { // 主要任务
        if (cur_time >= i.deadline) { // 这个时候我们要反悔完成过的任务。
            if (q.size()) { // 如果选过次要任务，先反悔次要，保证主要任务数量最大。
                auto t = q.top(); q.pop();
                p.push(i);
                main_cnt ++ ;
                val += i.val - t.val;
            } else { // 没有选过次要任务，只能反悔主要任务。
                auto t = p.top();
                if (t.val > i.val) // 反悔之后价值和反而变小，那就直接不反悔了。
                    continue;
                else { // 反悔可以是价值和更大
                    p.pop();
                    p.push(i);
                    val += i.val - t.val;
                }
            }
        } else { // 直接加
            p.push(i);
            cur_time ++ ;
            val += i.val;
            main_cnt ++ ;
        }
    } else { // 次要任务
        if (cur_time >= i.deadline) { // 我们只能从次要任务里面反悔。
            if (q.size()) {
                auto t = q.top();
                if (t.val > i.val) // 反悔之后答案不优
                    continue;
                else {
                    q.pop();
                    q.push(i);
                    val += i.val - t.val;
                }
            } else {
                // 搞不了
                continue;
            }
        } else { // 直接加
            cur_time ++ ;
            res += i.val;
            q.push(i);
        }
    }
}
```
