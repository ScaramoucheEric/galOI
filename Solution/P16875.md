# P16875 [GKS 2022 #B] Unlock the Padlock 区间DP

[题目来源](https://www.luogu.com.cn/problem/P16875)

## 题目概述：

给出 $n$ 个数字，每次操作可以使任意区间 $[l, r]$ 内的数字 $+1$ 或 $-1$，要求最后区间 $[1, n]$ 之间所有的数字都变成 $0$。特别的，$0$ 进行 $-1$ 操作后变成 $m$，$m - 1$ 进行 $+1$ 操作后变成 $0$。

## 思路：

首先，不难发现，将区间变成 $0$，必定会将这个区间全部变成同一个数，然后再一下子操作到 $0$。

那么就可以枚举区间 $[l, r]$ 变成 $k$ 所需要的最小操作数。

不难想到使用动态规划。

$dp_{l, r, k}$ 表示区间 $[l, r]$ 变成 $k$ 所需要的最小操作数。考虑dp从哪来：可以从 $dp_{l + 1, r, a}$ 转移来，也可以从 $dp_{l, r - 1, a}$ 转移来。

$$
dp_{l, r, k} = \min\{dp_{l + 1, r, a} + dist(a, k), dp_{l, r - 1, a} + dist(a, k)\}
$$

其中 `dist(a, k)` 是 $a$ 变成 $k$ 的代价，具体怎么算可以下面看代码。

这个做法是 $O(N^2D)$ 的，前两个点随便过，但最后一个过不了，肿么办呢？

仔细观察可以发现：

把一个区间的数全部变成区间中间的数，一定不优（随便手玩几个数据就会发现），所以我们把数变成区间最左或者最后端的数。我们优化一下DP状态，把最后一维设计为 $0/1$，代表区间 $[l, r]$ 全部变成最左端的数或最右端的数。然后就会得到优化后的DP方程：

$$

dp_{l, r, 0} = min\{dp_{l + 1, r, 1} + dist(arr[l], arr[r]), dp_{l + 1, r, 0} + dist(arr[l], arr[l + 1])\}

$$
$$

dp_{l, r, 1} = min\{dp_{l, r - 1, 0} + dist(arr[l], arr[r]), dp_{l, r - 1, 1} + dist(arr[r - 1], arr[r])\}

$$

然后这题就结束了。

AC代码（C++，码风可能有点怪，不喜勿喷喵~）：
```cpp
#include <cstring>
#include <iostream>
#include <algorithm>
#include <functional>
#include <vector>
#include <cstdio>
#include <queue>

namespace std {
    class Read {
        public:
        template<typename T>
        inline Read operator >> (T & u) {
            T sum = 0; short opt = 1;
            char ch = getchar();
            while(!isdigit(ch)) opt = (ch == '-') ? -1 : 1, ch = getchar();
            while( isdigit(ch)) sum = (sum << 1) + (sum << 3) + (ch ^ 48), ch = getchar();
            u = sum * opt; return *this;
        }
    };
}
#define int long long
#define all(a) a.begin(), a.end()
#define endl "\n"
#define IO(u) freopen(u ".in", "r", stdin), freopen(u ".out", "w", stdout);

using namespace std; Read fin;

const int INF = 0x3f3f3f3f3f3f3f3f;

void solve() {
    int n, m; fin >> n >> m;
    
    vector<int> arr(n + 1);

    for (int i = 1; i <= n; i ++ ) {
        fin >> arr[i];
    }

    vector<vector<vector<int> > > dp(n + 1, vector<vector<int> >(n + 1, vector<int>(2, INF)));

    function<int(int, int)> dist = [&](int a, int b) -> int {
        return min(abs(a - b), m - abs(a - b));
    };

    for (int len = 1; len <= n; len ++ ) {
        for (int l = 1; l + len - 1 <= n; l ++ ) {
            int r = l + len - 1;
            if (l == r) dp[l][r][1] = dp[l][r][0] = 0;
            else {
                dp[l][r][0] = min({dp[l][r][0], dp[l + 1][r][1] + dist(arr[l], arr[r]),
                                                dp[l + 1][r][0] + dist(arr[l], arr[l + 1])});
                dp[l][r][1] = min({dp[l][r][1], dp[l][r - 1][0] + dist(arr[l], arr[r]),
                                                dp[l][r - 1][1] + dist(arr[r - 1], arr[r])});
            }
        }
    }

    // for (int i = 1; i <= n; i ++ ) {
    //     for (int j = i; j <= n; j ++ ) 
    //         cout << i << " " << j << " " << dp[i][j][0] << " " << dp[i][j][1] << endl;
    // }

    cout << min(dp[1][n][0] + dist(arr[1], 0), dp[1][n][1] + dist(arr[n], 0)) << endl;
}

signed main() {
    #ifndef ONLINE_JUDGE
    IO("P16875")
    #endif

    int T; fin >> T;

    for (int C = 1; C <= T; C ++ ) {
        cout << "Case #" << C << ": ";
        solve();
    }
}
```
