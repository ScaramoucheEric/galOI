# P16875 [GKS 2022 #B] Unlock the Padlock 区间DP

[题目来源](https://www.luogu.com.cn/problem/P16875)

## 题目概述：

给出 $n$ 个数字，每次操作可以使任意区间 $[l, r]$ 内的数字 $+1$ 或 $-1$，要求最后区间 $[1, n]$ 之间所有的数字都变成 $0$。特别的，$0$ 进行 $-1$ 操作后变成 $m$，$m - 1$ 进行 $+1$ 操作后变成 $0$。

## 思路：

首先，不难发现，将区间变成 $0$，必定会将这个区间全部变成同一个数，然后再一下子操作到 $0$。

那么就可以枚举区间 $[l, r]$ 变成 $k$ 所需要的最小操作数。

不难想到使用动态规划。

$dp_{l, r, k}$ 表示区间 $[l, r]$ 变成 $k$ 所需要的最小操作数。考虑dp从哪来：可以从 $dp_{l + 1, r, a}$ 转移来，也可以从 $dp_{l, r - 1, a}$ 转移来。

$$
dp_{l, r, k} = \min\{dp_{l + 1, r, a} + dist(a, k), dp_{l, r - 1, a} + dist(a, k)\}
$$
