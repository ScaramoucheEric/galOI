# 有关 Token 的插件

想在 DSH 里实时看到 Token 消耗和费用，确实有几个很不错的插件可以做到，它们主要能在**会话头部、侧边栏、输入框**等位置，以徽标、仪表盘或悬浮窗的形式展示信息。

我把几款有代表性的插件整理了一下，你可以根据自己喜欢的查看方式来选：

### 📊 实时Token与费用监控插件一览

| 插件名称 | 主要展示位置 | 核心特点 |
| :--- | :--- | :--- |
| **dsh-token-monitor** | 会话头部徽标 + 主区"用量"页签 | 功能全面，提供历史趋势、热力图、详细请求记录，适合深度分析用量习惯。 |
| **dsh-peak-indicator** | 会话头部 + 每轮消息末尾 | 专注**峰谷计价**与账户余额，能显示距离高峰/闲时切换的倒计时，费用估算更精准。 |
| **dsh-meter** | 会话右上角 | 按会话计费，清晰区分缓存命中/未命中、高峰/空闲时段的费用构成。 |
| **dsh-token-gauge** | 侧边栏仪表盘 | 视觉化体验好，有**四种皮肤**（老式车机/马卡龙/极简/星空），以仪表盘形式展示Token速度和缓存命中率。 |
| **dsh-spend** | 右下角**悬浮窗** | 不占固定空间，可展开查看多维统计、时间序列图和详细调用明细。 |
| **dsh-api-usage** | 侧边栏底部 | **通过余额差值实测消费**，精度较高（¥0.01），并提供24小时消费柱状图。 |
| **dsh-island-go** | 输入框上方状态条 | 专为**DSH Go (Android App)** 设计，在输入框上方以极简文字显示上下文占用和本轮费用。 |
| **dsh-composer-tokens** | 输入框（纯客户端） | **实时计算你正在输入的内容**会产生多少Token，在发送前就能预估成本。 |

### 💡 如何选择？

*   **追求功能全面与深度分析**：**`dsh-token-monitor`** 是不错的选择，它提供了最详尽的数据面板。
*   **对价格敏感，希望精准把握峰谷时段**：**`dsh-peak-indicator`** 或 **`dsh-meter`** 会更适合你，它们对峰谷计价的处理更细致。
*   **喜欢视觉化、仪表盘风格**：**`dsh-token-gauge`** 的多种皮肤和仪表盘设计会让数据展示更直观。
*   **希望界面简洁，不占固定空间**：**`dsh-spend`** 的悬浮窗或 **`dsh-api-usage`** 的侧边栏小部件都是轻量级的选择。
*   **主要使用DSH Go (Android)**：**`dsh-island-go`** 是专为移动端原生设计的。
*   **想在输入时就控制成本**：**`dsh-composer-tokens`** 可以帮你实时预估发送前的Token消耗。

### ⚙️ 通用安装方式
大部分插件的安装命令都类似，以 `dsh-token-monitor` 为例：

```bash
dsh plugin --profile web add dsh-token-monitor
```

你也可以从GitHub直接安装，或通过DSH桌面版的"插件"页面粘贴地址进行安装。部分插件（如`dsh-island-go`）可能有特定的安装方式，建议查看其官方说明。

### 💎 一点提醒
这些插件显示的费用大多是**基于官方价目表的估算值**，并非最终账单，实际扣费请以DeepSeek官方账单为准。另外，像**dsh-token-monitor**这类功能丰富的插件，可能对Node.js版本有要求（如≥22.5.0），安装前可以留意一下兼容性说明。
